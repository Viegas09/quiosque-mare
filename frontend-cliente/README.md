# 📱 Frontend Cliente - App do Quiosque de Praia

App mobile (PWA) para os clientes fazerem pedidos no quiosque de praia.

## 🚀 Tecnologias

- **React 19** + **Vite** - Interface moderna e rápida
- **React Router** - Navegação entre páginas
- **Tailwind CSS** - Estilização responsiva
- **Socket.io Client** - Comunicação real-time
- **Axios** - Requisições HTTP
- **html5-qrcode** - Leitura de QR Code
- **Lucide React** - Ícones modernos

## ⚙️ Configuração Rápida

```bash
# Instalar
npm install

# Configurar
cp .env.example .env

# Rodar
npm run dev
```

Acesse: `http://localhost:5173`

## 🎯 Fluxo Completo

1. **Escanear QR Code** ou digitar número da mesa
2. **Ver cardápio** e adicionar itens ao carrinho
3. **Revisar pedido** no carrinho
4. **Escolher pagamento** (PIX)
5. **Pagar** e aguardar confirmação
6. **Acompanhar** pedido em tempo real

## 📱 Features

✅ Scanner de QR Code  
✅ Cardápio com filtros  
✅ Carrinho inteligente  
✅ Pagamento PIX  
✅ Status real-time
